# 维度四：治理响应与次生风险

Natural 与 D 共享至 Tick 3 后分叉。本报告只读复算冻结充分统计量；差值是配对分支最终时点的 `D−Natural`，不是标准双重差分估计。

## 指标定义

- 公开消息、直接回复：最终分支累计计数。
- 无依据主张流速：当前期新增未验证主张数除以当前期公开消息数。
- 服务积压/SLA风险：`0.6×backlog/(capacity+backlog)+0.4×sla_breaches/help_requests`。
- 干预直接质询率：收到严格直接回复或引用的治理消息数除以治理消息数；Natural 无治理消息，故不适用。
- 跨群曝光差：冻结利益组跨群信息曝光率的最大值减最小值。
- 群体信任度：最终 Tick 的1000名父智能体粒子加权 trust 均值。
