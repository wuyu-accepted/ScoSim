# 维度二：微观一致性与角色保持

## 案例与共同输入

实验使用暑期住宿床位分配争议：床位由 520 缩减至 320，共有 536 份有效申请。四种横向方法以及四种 CampusPulse 消融条件接收同一论坛结构、同一角色背景、同一可见上下文和同一事件事实。方法间只保留认知与记忆机制的差异。

横向比较使用 512 条共同观察。CampusPulse 将角色背景映射为静态画像与 10 粒子状态；Belief Engine 映射为论据库和对数几率状态；Generative Agents 映射为初始自然语言记忆；Chuang et al. 映射为闭世界历史和五档意见状态。

纵向消融包含纯上下文、仅 Profile、仅粒子状态和完整输入四个条件。状态条件共享冻结预热轨迹，禁止为不同条件单独预热或使用当前待生成输出构造前序状态。

## 数据与评测

- 文本评测包括上下文承接、无依据事实、表达—前序状态吻合和决策后状态—表达自洽。
- Generative Agents 与 Chuang et al. 没有与论文定义等价的显式前序内部状态时，该指标记为不适用，不补零。
- 语言风格一致性在同一智能体的非重复有效表达间计算。
- 消融条件识别使用支持向量机、留一智能体交叉验证和 999 次标签置换。
- 外部模型盲评结果属于模型辅助盲评，不应描述为真人受试者实验。

## 发布边界

公开 evidence 可以包含统一 JSONL 输出、冻结状态摘要、评分标签、分布和充分统计量；不得包含 API Key、原始 Provider 请求头、可恢复个人身份的数据或未脱敏私聊正文。

正式结果来源见两个子目录的 `evidence_index.json`。费用和调用类型见根目录 `usage/`。
