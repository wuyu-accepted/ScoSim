# 维度三：群体异质性与极化演变

## 案例与共同群体

实验使用同一住宿资源争议：床位从 520 缩减至 320，共有 536 份有效申请。冻结种子重建 1000 名持久合成智能体、逐智能体利益组和 8000 条有向关系边。所有方法使用同一事件事实、Tick 时序、父智能体身份集合和网络，不把 10 个粒子当作 10000 个独立个体。

横向比较从 Tick 0 演化至 Tick 9。CampusPulse 使用双层拓扑和 10 粒子 SMC；Belief Engine 沿冻结网络传递论据并更新对数几率；Generative Agents 依靠记忆检索、重要性和反思，并在指定切片实施全员五档问卷；Chuang et al. 使用闭世界记忆、诱导确认偏置和原生五档意见算子。

纵向机制消融比较完整输入、单粒子点估计、无 Profile 和无 Profile/无 SMC 四种条件。完整输入轨迹复用已经完成的正式 CampusPulse 数据，不产生重复 API 调用；其余三条件单独执行正式轨迹。

## 指标口径

- 全人群净立场统一到 `[-1, 1]`。
- 标准差采用总体口径 `ddof=0`。
- Sarle BC 使用普通中心矩估计；`5/9` 只作形态参考，不能单独证明双峰。
- KDE 使用 Gaussian kernel、Scott 带宽，并报告显著局部峰数。
- 信息熵使用 20 个等宽箱，边界为 `-1.0, -0.9, ..., 1.0`。
- 利益组解释度使用单因素多元 R²，并执行 199 次标签置换检验。
- Generative Agents 的问卷探针费用必须与主模拟、嵌入、重要性和反思调用分开报告。

## 数据边界

所有个体均为合成智能体，结果不代表真实学生意见，也不构成真实政策效应。公开文件应保留匿名全人群净立场向量或充分统计量、指标结果和来源哈希，不发布 API 凭据或可恢复身份的连接键。

正式结果来源见两个子目录的 `evidence_index.json`。费用和调用类型见根目录 `usage/`。
